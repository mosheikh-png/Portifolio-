# Pre-Handover Engineering Audit

هذا المستند هو نسخة المشروع من ملف التدقيق المقدم، ويُستخدم كمرجع قبول هندسي عند مراجعة البورتفوليو قبل تسليمه لمطور آخر. لا يغيّر هذا المستند التصميم أو المحتوى؛ بل يحدد متطلبات الحفاظ على الخلفية الثابتة، الحركة، الاستجابة، الترجمة، لوحة CMS، الأمان، الأداء، وإمكانية الوصول.

## نطاق الدمج الحالي

تم اعتماد الملف كمرجع للتكامل التدريجي، مع التركيز على مسار المشاريع ولوحة التحكم. أصبح كل مشروع يدعم عنوانًا ووصفًا إنجليزيين، مع عنوان ووصف عربيين اختياريين داخل نفس نموذج الإضافة والتعديل. وتظل الصورة، الرابط، التصنيف، ترتيب الظهور، حالة النشر، والحذف قابلة للإدارة من لوحة المالك.

## قاعدة مصدر الحقيقة

تأتي المشاريع العامة من استعلام `cms.publicProjects` فقط. لا توجد مشاريع تجريبية بديلة في صفحة التصنيف؛ عند عدم وجود مشاريع منشورة تظهر حالة الفراغ المترجمة بدل عرض بيانات غير قابلة للإدارة.

## بوابة التحقق

قبل تسليم نسخة جديدة، يجب تشغيل فحص TypeScript والاختبارات ونسخة الإنتاج، ثم مراجعة المسارات العامة باللغة الإنجليزية والعربية، ومسار لوحة التحكم للمشاريع، ورفع الصورة، والحفظ، والتعديل، والحذف، والتبديل بين RTL وLTR. يجب الحفاظ على الهوية البصرية الحالية وعدم إدخال طبقة خلفية أو تنفيذ UI مكرر.
